I don't like adding Skadis pegs to my models. I also don't like printing a Skadis model I like, and then being unable to use it because the hooks snap off.

So I made this tool to generate the pegs for you. It quickly allows you to put pegs on a model and print it, without having to faff around designing them.

Access it at [Skadisgen.com](https://skadisgen.com).
Or on [Printables](https://www.printables.com/model/1546768-skadis-peghook-generator).
